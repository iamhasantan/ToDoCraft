# ToDoCraft

A clean-room, Rust-native task manager targeting Microsoft To Do feature parity, following [Storytold Craft](https://github.com/storytold) design principles.

Development takes place on feature branches and is reviewed through pull requests. See the initial implementation pull request for the desktop application, parity checklist, and architecture.

This project is independent of Microsoft and Storytold. No Microsoft or ArtCraft branding or assets are included.
